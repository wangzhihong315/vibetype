# 动效规范

[English](en/motion.md) · 中文

目标：所有反馈在 300ms 内完成，用户永远知道「刚才那一下有没有被接住」。
参考 iPhone 原生 App 的节奏：短、克制、可打断；不做装饰性动画。

## 时长

| 场景 | 时长 | 曲线 |
|---|---|---|
| 按键按下 | 110ms | ease-out |
| 按键回弹 | 140ms | spring（阻尼 0.85） |
| 录音浮层进出 | 220ms | ease-in-out |
| 结果卡进出 | 240ms | spring |
| 底部 sheet | 280ms | 系统默认（M3） |
| 存胶囊飞入 | 680ms | FastOutSlowIn |
| 页面切换 | 300ms | ease-in-out |

## 触觉

- 语音键 / 胶囊键按下：`LongPress` 一次
- 胶囊保存成功：`LongPress` 一次
- 失败：不震，用颜色和文案说明

## 组件

### 按键

- 按下缩到 **0.97**，回弹回 1.0；不改变颜色以外的布局
- 胶囊键按住 240ms 才开麦：底部画一条 240ms 的珊瑚色进度
- 胶囊键右上角显示未同步条数（`9+` 封顶），同步后消失

### 录音浮层

- 浮在触控板上，不换页
- 光晕随音量变化，计时每秒跳一次
- 长句只显示最新的 96 字（前面 `…`），让用户看到「正在识别」

### 结果卡

- 成功：5 秒后自动收起；超过 40 字显示「共 N 字 · 点开看全文」
- 失败：保留，可点按重发
- 不做自动重试：避免重复上屏

### 底部 sheet

- 一律全展开（`skipPartiallyExpanded`），内部可滚动
- 下滑可关；关闭不丢草稿（胶囊编辑除外）

### 胶囊飞入

- 卡片从中间缩小飞向左下角胶囊键，680ms
- 只做视觉确认，不阻塞下一次录音

## 可打断

- 录音中松手立即结束，不等动画
- 结果卡出现后可直接开始下一次录音，旧卡立即让位
- 所有动画只影响透明度 / 缩放 / 位移，不改布局尺寸，避免触控目标漂移
