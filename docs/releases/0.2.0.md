# VibeType 0.2.0

首个公开版本：**手机说话，电脑上就出字。**

语音在手机本地用 X-ASR 转写，只把文字通过局域网 TCP 发给 Mac / Windows；电脑端不需要声卡驱动、不依赖输入法，直接把字打进当前焦点。手机同时是一块触控板和一个闪念胶囊收件箱。

VibeType 0.2.0 — say it, it types. Speech is transcribed on the phone; only text crosses the LAN. No virtual audio driver, no IME dependency, and the phone doubles as a trackpad and a thought-capsule inbox.

## 亮点 / Highlights

- **本地流式转写**：X-ASR 960ms，中英混说，带标点，边录边出字；音频不出手机。
  On-device streaming ASR (X-ASR 960 ms), zh-en mixed speech with punctuation; audio never leaves the phone.
- **编程与 AI 词汇**：144 条热词、171 条别名、182 条大小写规则、5 条上下文规则，覆盖 JSON、Swift、Node.js、GitHub Actions、Claude Code、ChatGPT、Hugging Face、RAG、MCP 等。
  144 hotwords, 171 aliases, 182 casing rules and 5 context rules for coding/AI terms.
- **闪念胶囊**：按住胶囊键说一句，手机本地转写并保留原件；连上电脑后自动补发。桌面端完整留档，MCP 默认只取 20 条未消化的，避免把上下文塞满。
  Thought capsules: hold, speak, keep the original on the phone; unsynced items are resent on reconnect. The desktop keeps the full archive; MCP returns 20 unprocessed items by default.
- **配对与重连**：六位码或二维码配对，手机可直接用后置相机扫电脑上的二维码；换 Wi-Fi / 换办公室后自动 UDP 发现，连不上还能手动改地址，不用重新配对；半开连接 45 秒判定并重连。
  Pairing by code or QR (the phone can scan the desktop QR); automatic UDP discovery after network changes, manual address fallback, and half-open connections detected after 45 s.
- **触控板与按键**：指针、双指滚动、右键、捏合缩放、长按拖动；五个键可在桌面端映射成按键或「打开/切到某个应用」。
  Trackpad gestures plus five configurable keys, mapped on the desktop to a key or to launching/focusing an app.
- **桌面控制台与 MCP**：macOS / Windows（Tauri 2）；`vibetype --mcp` 提供胶囊读写、打字到光标等工具，附 Prompt 与 Skill。
  Desktop console on macOS/Windows, plus a local stdio MCP server with a prompt and skill for capsule digestion.
- **双语与深浅色**：手机和桌面都可中英切换、跟随系统或手动外观。
  Chinese/English UI and light/dark themes on both ends.
- **界面**：主屏胶囊键换成 Blender 渲染的 3D 单粒红药丸，按住有灌注进度和录音声波。

## 这一版修掉的问题 / Fixes

- 重连成功后退避不归零，导致断线越等越久。
- 半开连接一直显示「已连接」，现在 45 秒读超时后自动重连。
- 旧连接的协程可能覆盖新连接状态；旧 socket 现在只关自己。
- 并发同步胶囊会丢更新；写入已串行化。
- 深色模式下断线页的白底按钮文字几乎看不见。
- 桌面端原先只保留最新 200 条胶囊；现在完整留档，条数限制只放在 MCP 查询上。

## 已知限制 / Known limits

- Android 仅提供 arm64-v8a；模型随 APK 打包，安装包较大。
- macOS 安装包未签名、未公证，首次打开需要右键 →「打开」。
- Windows 安装包由 CI 构建，尚未在真实 Windows 机器上完整验证。
- 桌面 MCP 单次最多返回 200 条胶囊（默认 20）。
- 英文识别仍有口音与短词误判，术语层只能修正已知词汇。

## 安装 / Install

- **Android**：侧载 APK（Android 9+，arm64），或用 `adb install -r app-release.apk`。
- **macOS**：Apple Silicon DMG。
- **Windows**：x64 NSIS / MSI。

构建产物由 GitHub Actions 在 `v*` 标签上生成（Android APK、macOS DMG、Windows 安装包）。
Builds are produced by GitHub Actions on `v*` tags.
