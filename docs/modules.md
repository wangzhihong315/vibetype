# 功能模块

状态：✅ 已实现　◐ 部分实现　○ 未实现

## 一、共用能力

| # | 模块 | 职责 | 状态 |
|---|---|---|---|
| C1 | 配对与连接 | 二维码 / 六位码配对，换长期 deviceToken；心跳保活、断线重连、配对失效回退 | ✅ |
| C2 | 本地语音识别 | X-ASR 960ms 流式 zh-en + 标点 + 热词；术语纠正层；粤语/日/韩切 SenseVoice | ✅ |
| C3 | 文字上屏 | 按键注入（CGEvent / SendInput），失败退到剪贴板粘贴；ack 回报 | ✅ |
| C4 | 胶囊存储与同步 | 手机录音、本地转写、本地持久化；按需同步到桌面收件箱 | ○ |
| C5 | 模型管理 | 当前随 APK 打包；后续可独立更新模型 | ◐ |
| C6 | 诊断 | debug 自检（内置录音跑全链路）、连接错误提示、版本信息 | ◐ |
| C7 | 指针通道 | 手机触控板的移动 / 左键 / 右键 / 滚动（双指与边缘），走同一条 TCP 连接，桌面端转成鼠标事件 | ○ |
| C8 | MCP 服务 | 本地 stdio MCP：读取转写、胶囊读写、打字到光标、按键控制（默认关） | ○ |

## 二、手机端（Android）

| # | 页面 / 模块 | 关键内容与状态 | 阶段 |
|---|---|---|---|
| P1 | 首次引导 | 产品一句话、麦克风权限、去连接电脑 | ○ |
| P2 | 配对 | 地址 / 端口 / 六位码；连接中、失败、配对失效 | ✅ |
| P3 | 遥控器主屏 | 一块触控板 + 语音键 + 胶囊键 + 回车 / 删除 / Esc / 切换 / 自定义；轻点左键、双指滚动、双指轻点右键、长按拖动 | ✅（只有语音） |
| P4 | 语音浮层 | 录音中（电平、计时）、转写中、已上屏、上屏失败；全部浮在触控板上 | ◐ |
| P5 | 胶囊浮层 | 按住胶囊键录制；松开自动转写并保存 | ○ |
| P6 | 胶囊列表 | 从底部滑出的 sheet；全部 / 未转写；空态 | ○ |
| P7 | 胶囊详情 | 全文、时长、复制、发到电脑光标、删除 | ○ |
| P8 | 设置 | 电脑 / 遥控器（灵敏度、自定义键、按键映射）/ 转写 / 胶囊 / 关于 | ◐ |
| P9 | 手势 | 顶部演示台循环播放当前手势 + 六种手势列表（单指移动、轻点、长按拖动、双指滑动、双指轻点、边缘拖动）；点一行就播那一行；首次自动打开，之后从设置进 | ○ |
| P10 | 状态与异常 | 未连接、token 失效、模型加载失败、权限被拒、上屏失败 | ◐ |

## 三、桌面端（macOS / Windows）

| # | 页面 / 模块 | 关键内容与状态 | 阶段 |
|---|---|---|---|
| D1 | 首次设置 | macOS 辅助功能权限、配对；没有侧边栏，两步走完再进主界面 | ◐ |
| D2 | 概览 | 手机 / 上屏权限 / MCP 三张状态卡；最近上屏；显示配对码、暂停接收、打开胶囊 | ◐ |

| D8 | 托盘与提示 | 打开 / 暂停接收 / 退出；上屏失败 HUD | ◐ |

### MCP 工具（四个）

| 工具 | 作用 | 默认 |
|---|---|---|
| `transcripts.recent` | 读取最近的转写结果 | 开 |
| `capsules.list/get/create/delete` | 读取与写入胶囊 | 开 |
| `text.type` | 把文本打进当前光标 | 开 |
| `keys.press` | 回车 / 删除 / Esc，白名单按键 | 关（危险） |

实现方式：桌面 App 带一个 `--mcp` 子命令，走 stdio JSON-RPC；配置片段由 D6 页一键复制。

## 四、明确不做（本阶段）

- 云同步、账号体系：胶囊与记录都留在本地。
- 移动端 iOS：没有开发者账号，先把 Android 做透。
- 蓝牙 HID：触控板改走已有 TCP 连接，不再维护一套 BLE HID 协议。
